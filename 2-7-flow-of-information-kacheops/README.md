# Your Task
The goal of this activity is to use and practice your knowledge of Python dictionaries to understand the structure and function of a JSON object. Once you paste (or click) on the URL, a JSON object will be returned to you. Take a good look at it. See if you can identify all of the object's keys and their corresponding values. How many keys are there? How is the data structured? Where are the square brackets and where are the curly ones? Is it a dictionary of lists or a list of dictionaries? Can you use your understanding of lists to isolate one dictionary? Can you write a Python program that does that?

To get you started, try the following: Copy all of the text returned from the API after entering the URL (We will call that the data blob).  Set it to the variable data in your code:

```
data = the data blob   # the data blob is the data you copied that was returned from the website: the JSON object
print(data[2]['type'])   # In this line, what is the purpose of the number 2? What is the purpose of the word 'type' ?
```

This is the beginning of your exploration. Use your knowledge and skill to manipulate the data that was returned to you. In the end, tell me what you discovered and send me the program you built. The only requirement of this assignment is to answer the questions listed in the submission directions below.
