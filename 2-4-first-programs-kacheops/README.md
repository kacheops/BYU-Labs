# Lab

**You will use the first_program.py file to write your code**

Now it's time to create your very first Python application! Write a program that asks questions of the person using the program (i.e the user) and then uses those answers to create a message that will be sent to the user. The pseudo-code for the program looks like this:

1. Print a greeting.
2. Ask for a name.
3. Collect the name entered by the user and store it in a variable called name.
4. Ask the user what city they were born in.
5. Collect the name of the city entered by the user and store it in a variable called city.
6. Create a message by combining [literal strings](https://www.w3schools.com/python/python_string_formatting.asp) (strings you define) and the information stored in the variables (Represented below by curly braces and variable names, for example: {city} ) into a meaningful message. Think of it as a Mad Lib:

    "Hello, " + {name} + "! I have heard that {city} is a fascinating place!" or
    "Good morning, " + {name} + "! I have always wanted to visit {city} !"    (or something similar)

7. Print out the message!

In order to implement this pseudo-code in Python, you will need to know:

- How to print out literal text
- How to collect user input and assign it to a variable.
- How to concatenate (i.e. join) literal text with the contents of a variable. (Hint: look to see how it was done in the example)

Make sure you have learned how to do those things from the readings!

**The code you will be expected to learn in this course will gradually increase in difficulty. Reflect on the process illustrated in this lab:**

1. Generate pseudo-code that spells out the 'flow' of the program; in other words, articulate the sequence of steps that the program will move through to accomplish its task.
2. Then translate those English-friendly steps into Python commands. Arrange those commands in a syntactically correct way, and then
3. Run the program to see if it works. Syntax errors (Usually errors in spelling or word order) are very common for beginners.
4. You will, usually, have to Debug (i.e. find and fix errors) in your code. Use examples from the readings to help you write the code correctly. Pay attention to spelling and word order.
5. You will use this same process again and again!

Click the terminal in the codespace and type `pytest` to test your code.
